# 视频解析（Android）

粘贴抖音、快手或哔哩哔哩的公开分享链接/分享文案，应用会解析作品信息。视频作品可在应用内预览并下载 MP4；抖音和快手图文作品会进入双列图片页，可逐张查看或下载。

## 使用

1. 安装 `v0.24/LinkVideo-v0.24-debug.apk`（调试签名，仅供测试）。启动公告增加免费开源防骗、个人使用责任和抖音网页认证提示；正文区域可上下滑动，底部“不再显示”与无背景“关闭”位于同一行。设置页右上角喇叭图标可随时查看公告。“显示抖音解析网页”默认关闭；隐藏读取约 8 秒无实际进展，或等待约 16 秒仍未取得作品时，在当前页面自动显示同一个官方网页。不开启持久化开关，应用在后台时不主动弹窗。手机 WebView 效果待实机复测。
2. 打开应用，点击“粘贴并解析”，或先填写链接后点击“解析”。
3. 视频结果按“视频封面、平台、文案、作者/时长、四宫格按钮”显示，并支持应用内播放、复制地址、下载 MP4 和下载封面。文案可直接修改，底部“复制”按钮将文本框当前内容复制到剪贴板。
4. 抖音或快手图文结果会自动打开图片页。顶部提供返回箭头和居中的“由@UMG_gudian114开发”水印，色彩沿用主页。标题下方显示可编辑文案框与“复制”按钮；图片按两列从上到下排列，不同比例分别适配；每张图片下方提供“下载图片”和“查看图片”。
5. “查看图片”会在应用内全屏显示；下载的图片保存在系统的 `Pictures/拾链` 目录。
6. 主页顶部显示“由@UMG_gudian114开发”，右上角齿轮进入设置。“当解析完视频下一条链接是图文”默认“清除解析的视频内容”，也可选择“保存解析的视频内容”；选择会保存到下次启动。
7. 平台名称下方的“批量解析”进入视频批量页：初始一个输入框，只有换行才新增/切换下一框并保留当前文字，最多十个输入框。退格正常删除文字，已为空时再退格删除该框（至少保留一个）；后续框重新编号，链接和已解析结果随原框保留。空内容（含纯空白）换行会弹出“内容不可为空”，不会打开下一框。每项“解析”占满上行，“重新解析”和“清空链接”位于下行。
8. 批量页底部“一键解析”依次处理所有非空框中的链接，“一键下载”保存所有已解析视频的 MP4 并显示逐项进度和文件位置，“一键清空”重置批量列表，只保留一个空框。图文弹窗“此操作仅限与视频批量解析”，跳过该项并继续其他链接；单条图文请使用主页。
9. 批量页顶部计数（例如 1/10）记录文本框数量，点击进入多选。顶部出现“删除”“全选/取消全选”“取消”；勾选视频后“一键下载”只下载选中项，空选择不会下载全部。取消选择后恢复原顶部和默认下载全部。设置中“批量解析选择设置”下拉框三选一：优先选择视频（默认）、每次询问选择类型、视频与文本框同删除。每个选项旁的问号可长按查看对应帮助。默认删除视频仅清除结果保留链接；第三模式删除选中视频及对应文本框，均不删除手机已下载文件。
10. 设置的三个批量按键开关默认 ON；开启一个时占满一行，开启两个时上下排列，全部开启时恢复三按钮布局；全部 OFF 时仍可使用底部一键操作。
11. 批量解析前，提取出的同一链接重复出现会询问“检测到相似链接是否继续解析”。选择“是”照常解析，选择“否”显示“1与2与3相似”等输入框编号，让用户自行修改。单项解析也会检查与其他框重复的链接；不同短链不会仅凭文字近似而合并。

12. 网络解析失败后，主页或对应批量项会出现“查看错误详情”；打开后点击“复制错误详情”，可将诊断文字发送给开发者。包含版本、Android 版本、本机时间、每一步的 HTTP 状态、耗时、返回类型与数据结构摘要；不包含完整链接、签名、Cookie 值或分享文案。当前不会自动上传诊断。隐藏网页读取失败时，详情页提供“网页显示设置”，可开启后重试；开关选择会保存。

单个输入框的清空或编辑、解析失败不会清除已经解析的视频。批量“一键清空”会重置整批记录。下一条解析为视频时替换主页面旧结果；下一条解析为图文时按设置清除或保留旧视频。以上操作不会删除已经下载的文件。

“批量解析后预览视频”默认关闭；在设置打开后，成功项以主页同款视频卡片替换输入区，失败项仍可编辑。支持封面、播放/暂停、时间轴、文案编辑与复制，以及视频/封面下载等操作。同时只播放一条，点击其他视频播放时暂停前一条并保留进度。批量页右下角的圆形向上/向下按钮可以快速到顶/到底。

“返回主页时是否清空批量解析内容”默认关闭：返回主页后再进批量页，会恢复链接、解析结果、修改后的文案及下载位置。开启后返回主页清空批量草稿；打开设置不触发清空。已过期的媒体地址需要重新解析。

解析期间显示横向进度条与百分比，按链接识别、页面获取、数据读取和媒体信息整理等实际步骤推进，成功或失败后自动隐藏。百分比表示步骤进度，不估算剩余时间。

退出批量页会取消队列，并在当前解析的网络请求、重定向、读取及后备解析步骤之间检查取消状态。已经阻塞的网络操作可能需等待连接或读取超时后才能结束。

应用不读取账号、不导入用户 Cookie、不把链接发送给第三方解析服务。Android 10 及以上不请求存储权限；Android 8/9 首次下载会请求存储权限。请只处理你有权保存的内容，并遵守来源平台的规则。

## 当前支持边界

- 哔哩哔哩：BV、av、b23.tv 单视频链接；DASH 会选择 H.264 画面与 AAC 音频并在本地封装为 MP4。暂不解析哔哩哔哩图文作品。
- 抖音：公开短链、视频链接和图文链接；图文兼容旧版 `images` 与新版 `image_post_info` 页面数据。分享页没有返回作品时，会初始化匿名会话、完成平台返回的注册回调，并使用本地生成的签名请求网页作品详情。以上步骤仍未取得作品时，加载官方作品页并监听该作品数据。设置开启时立即显示；关闭时先隐藏读取，停滞后在前台自动显示。显示后留出 60 秒供平台认证，成功后立即关闭，也可取消本条解析。未显示时网页阶段等待上限 25 秒，主线程异常时外层最多等待 90 秒。保留平台返回的信息，不导入外部浏览器账号或 Cookie。
- 快手：公开短链、视频链接和图集链接；图集兼容当前 `atlas` CDN、图片列表及尺寸数据。
- 登录、付费、区域限制、验证码、已删除作品或平台页面结构变化仍可能返回失败提示。

平台没有提供稳定的通用下载 API，因此“支持”表示应用会尝试解析公开页面，不保证任意链接始终可用。图片加载会依次尝试平台提供的备用地址，并校验返回内容，避免把错误页面保存成图片。

## 从源码构建

需要 JDK 17、Android SDK 35、Build Tools 35.0.0。用 Android Studio 打开本目录，或在 PowerShell 中运行：

```powershell
.\gradlew.bat assembleDebug
```

标准调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。设计与实现计划位于 `docs/superpowers`，验证结果见 `docs/verification.md`。
