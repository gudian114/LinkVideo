# v0.3 抖音与下载反馈修复

1. 抖音：补充从落地页正文提取作品编号；保留短链和分享页返回的 Cookie；页面仍无作品数据时，主动向字节跳动注册端点获取匿名 `ttwid`，再请求带 `aid=1128&app_name=aweme` 的抖音作品详情接口。
2. 快手下载反馈：下载按钮点击后立即显示“正在下载”，并在按钮下显示横向进度条、百分比、已下载大小和总大小。
3. 文件位置：下载完成后查询系统媒体库中的实际文件名，并显示 `下载/拾链/<实际文件名>.mp4`。
4. B站：保留 v0.2 的 H.264 画面与 AAC 音频本地封装逻辑。

截图中的抖音短链 `TrnjluhvzCk` 在线复测时只跳转首页，页面中也没有作品编号，无法恢复原作品。当前仍有效的公开短链已经完成在线解析验证。

抖音回退流程参考了 MIT 许可的 [DyExtract](https://github.com/Hartcher1996/DyExtract) 中 `ttwid` 注册与作品详情请求顺序，并按本应用现有 Java 网络层做了精简实现。
