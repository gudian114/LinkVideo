# v0.4 界面与操作调整

1. 解析结果顺序改为：视频封面 → 平台 → 文案 → 作者/时长 → 四宫格按钮。
2. 删除“媒体地址”标题、说明、长链接和轨道卡片。
3. 四宫格按钮为“查看原视频”“复制视频链接”“下载视频(mp4)”“下载视频封面”。
4. “查看原视频”使用解析后的视频地址打开系统浏览器，并附带解析结果中的来源请求头；“复制视频链接”复制同一个地址。
5. B站存在完整媒体流时优先使用完整流，DASH 结果回退到视频轨。MP4 下载继续在应用内合并 H.264 画面和 AAC 音频。
6. 视频封面按平台返回的图片格式保存到 `下载/拾链`，完成后显示实际文件名和位置。
7. 从本版本开始，每次交付使用独立的版本号文件夹。
