# v0.11 抖音图文解析修复与图片页导航

用户样例：https://v.douyin.com/9frk6FTp2Dk/。

短链跳转至 `share/note/7685366931792203054`。当前分享页只返回页面配置与作品编号，缺少 `videoInfoRes` 和图片列表。旧版继续请求旧 `iteminfo` 和未签名的详情接口，没有返回公开作品数据，因此报错。

排查对照了官方页面的运行时代码以及公开解析器。专用 `slidesinfo` 在当前网络返回空图片列表与过滤标记；没有将该 HTTP 200 响应当作成功。最终验证的有效请求是网页详情接口、`aid=6383`、`device_platform=webapp`、目标作品编号、实际生成的 `a_bogus` 签名以及匿名 `ttwid`。

应用保留旧解析流程，在旧流程没有作品数据时执行签名回退。签名在手机本地生成，不调用第三方在线解析服务。回退的作品编号必须与分享链接一致。

2026-09-16，正式 Java 解析器返回目标作品的 10 张图片，作者“小隆在西部”；正式 `ImageLoader` 成功读取首图 970093 字节。此结果证明当时电脑网络下的解析及首图读取，不等同于手机上完整十张图片下载验证。

图片页导航采用固定顶部栏、左侧返回箭头和居中的 `UMG_gudian114` 水印，下方保持双列图片布局。颜色取自主页资源，查看图片仍在应用内全屏打开。

签名参考来源与许可证见 `third-party-notices.md`。本版本的构建和校验结果见 `verification.md`。
