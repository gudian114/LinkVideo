# v0.12 文案编辑与复制

## 行为

图文解析完成后，图片页固定顶部显示返回箭头和“由@UMG_gudian114开发”。其下的滚动内容先显示文案编辑框与“复制”按钮，再显示原有双列图片。图片比例适配、逐张下载与应用内全屏查看保持原样。

视频解析完成后，原来的文案文本换成同一套编辑框与“复制”按钮，仍位于平台和作者/时长之间。视频预览与四宫格按钮保持原样。

编辑框初始化为解析结果的完整标题/文案。点击“复制”时读取编辑框当前内容，复制用户修改后的文本，保留换行与空格；即使用户删除全部文案，也不回退复制旧内容。编辑只影响展示和复制，不改变下载所使用的解析结果。

## 实现边界

`view_caption_editor.xml` 和 `CaptionEditor.java` 由两个页面共用。文案仅在显示新的解析结果时初始化，没有输入变化触发的解析，也没有把分享链接输入框与文案框联动。主页面清空链接或下一次解析失败，不重置已编辑的视频文案。

文案不写入持久存储。图片页使用 Android 编辑框的视图状态保存机制；返回全屏图片查看时不重新绑定文案。

## 验证

保持现有核心回归测试，运行资源处理、Android Java 编译、Lint 和 APK 构建；核对安装包中两个页面均引用同一编辑组件，以及水印与“复制”资源。界面编辑和系统剪贴板交互需要真机安装验证，详见 `verification.md`。
