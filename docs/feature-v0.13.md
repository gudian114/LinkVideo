# v0.13 图文切换设置与解析进度

## 图文切换

主页右上角“设置”进入同配色设置页。当前只有“当解析完视频下一条链接是图文”及一个下拉选项栏：

- 清除解析的视频内容
- 保存解析的视频内容

首次使用默认清除。通过 SharedPreferences 保存选择，应用重启或升级后继续使用该选择。

只有图文解析成功后才读取设置。默认清除时，移除旧视频状态，停止预览、取消旧封面任务、清空文案和作者等展示信息，隐藏主页视频结果及下载提示。保存时保持原视频和已修改的文案，图片页返回后可继续预览、复制和下载。

该设置仅处理主页面已解析的视频结果，不删除磁盘文件。清空分享链接、解析失败或仍在等待解析，不清理原结果。成功解析新视频时照常替换。

## 解析进度

VideoParser 新增带 ProgressListener 的 parse 重载，旧调用方式继续可用。三个平台在真实步骤完成或回退请求开始时报告进度；百分比单调推进，成功构造解析结果后才报告 100。失败不报告完成。

主页面显示蓝色横向进度条和百分比，成功与失败都统一隐藏。异步进度和结果使用同一请求编号校验，旧请求不能覆盖新请求的界面。

百分比反映预设解析步骤的进度，不按计时器增长，也不表示网络字节比例或剩余时间。图文与视频都通过同一解析入口，因此两者均显示进度。

## 验证

默认清除旧视频用例在旧实现下按预期失败。新增保存分支、三个平台进度和失败不报告完成的核心测试，当前 100 项通过。完整构建、Lint、安装包与设备交互检查见 verification.md。
