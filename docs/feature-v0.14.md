# v0.14 视频批量解析

主页增加固定开发水印栏和齿轮设置。“批量解析”蓝色入口位于平台名称下方、分享链接卡片上方，进入独立视频批量页。

## 输入与按键

初始一个框，最多十个。回车、换行、退格只打开或切换下一框，当前文字全部保留；从前面的框操作会复用已有下一框。批量自定义输入控件拦截软键盘 backward delete、code-point delete 和按键请求，实体键盘退格也被拦截。清空文字使用“清空链接”或“一键清空”。粘贴一段多行分享文案保留在当前框，输入变化不会自动解析。

每项默认蓝色“解析”占满上行，绿色“重新解析”和浅红色“清空链接”平分下行。设置新增三个 ON/OFF 开关，默认全部 ON：批量解析解析按键、批量解析重新解析按键、批量解析清空链接按键。启用一个占满一行，两个上下占满，三个恢复上单下双；全部关闭时隐藏每项按钮，仍保留一键操作。设置持久保存，返回批量页即时重建按钮。

## 解析和下载

底部依次为蓝色“一键解析”、绿色“一键下载”、浅红色“一键清空”。解析读取各框现有链接，跳过空框，按顺序处理；逐项显示真实解析阶段进度，失败不影响后续链接。

批量仅限视频。解析器检测到图文后，弹出“此操作仅限与视频批量解析”，该项显示同样提示，跳过并继续其他链接。重复图文不堆叠尚未关闭的弹窗；不会进入图片页或把图片加入视频下载。主页单条图文解析与图片功能保持原样。

一键下载复用原有 MP4 下载/封装与 Android 存储流程，按顺序下载所有已解析视频，每项显示进度和下载后的位置。修改或清空链接不删除已有解析视频或下载文件；新的成功视频结果替换该框结果，失败或图文保留该框原视频。

批量任务期间禁用输入和重复操作，退出页面取消队列及当前任务。屏幕重建保存各框输入、结果与文件位置；进行中的任务取消，可再次执行。

## 验证范围

批量状态和串行队列新增十一项独立 JUnit 测试，与原有核心回归共同运行。资源编译、Android Java 编译、Lint、APK 版本和签名以 verification.md 记录为准；软件键盘行为和十项下载需设备实测。
