# v0.16 抖音会话、批量输入与重复确认

## 抖音会话修正

当前截图对应的公开分享页返回路由与环境信息，未包含作品详情；本机可通过匿名详情请求取得视频。代码检查发现匿名注册后未处理平台返回的 redirect_url，刷新 ttwid 时又覆盖分享页 Cookie。

本版完成注册回调，合并分享页、注册及回调的完整匿名 Cookie。回调仅接受 HTTPS www.douyin.com、默认/443端口、无 userinfo、精确 /ttwid/union/register/callback/ 路径。回调普通网络失败保留原注册信息，取消仍向上传递。注册失败也会使用已有会话尝试签名详情，不再直接跳过。

平台注册接口的真实响应包含 redirect_url；本机完成回调后返回 HTTP200 和 ttwid。详情请求有匿名 ttwid 时可返回视频与图文，没有会话的对照返回空内容。初始化匿名会话是本机验证得到的必要条件；没有手机日志，不能据此声称已确认用户手机失败的唯一原因。

## 批量输入

退格恢复正常删除，不打开下一框；输入法 composing 删除和选区删除也不导航。回车产生换行时打开或复用下一框并保留当前文字，最多十框。单次插入换行会被恢复为原文字，再由批量状态决定是否打开下一框；多行分享文案粘贴仍保留在当前框。

空内容或纯空白换行弹出“内容不可为空”，不创建或切换下一框。空白判断包括普通空格、全角空格、EM SPACE 和 NBSP，兼容最低 Android API26。编辑或清空输入仍保留已解析视频和下载位置。

## 重复链接

单项或一键解析前，使用既有识别器提取链接，按同一 URL 分组，不请求网络。仅提示本次要解析的项涉及的重复组。

弹窗“检测到相似链接是否继续解析”，按钮“是”“否”。“是”开始原有串行解析；“否”不解析，第二个弹窗显示“1与2相似”“1与2与3相似”等编号。存在多个重复组时逐行列出。编号来自现有输入框，范围1–10。

分享文案不同但链接相同仍为同一组；短链路径大小写保持原样。识别失败的非空内容不会被重复检查排除或判为无效，仍交给原解析流程；本版不新增无效链接统计。暂缓需求见 deferred-invalid-links.md。

## 验证

独立核心测试136项，其中输入/空内容规则的三项在旧实现失败；七项会话回归覆盖注册回调补齐、完整Cookie保留、原分享信息保留、普通失败、取消、回调来源限制与注册失败后的已有会话；缺失重复分组接口的测试先编译失败，再通过。

只读复审已无剩余重要问题。最终 APK、签名、Lint、真实链接与归档证据见 verification.md。未在手机或模拟器上验证，用户需测试设备网络和自己的输入法。
