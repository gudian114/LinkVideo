# v0.20 网页显示设置

用户希望隐藏官方页面，或通过设置选择是否显示。

- 设置新增“显示抖音解析网页”ON/OFF 开关，默认 OFF，独立 SharedPreferences 键 show_douyin_parse_page，保存选择。
- 主页和批量通过同一个 AndroidHttpClient，在创建网页会话时读取该值。原生接口已成功时不使用网页后备流程。
- OFF 时不创建网页对话框。WebView 插入应用内容层后方，保持附着和完整测量，alpha=0，禁用焦点和无障碍访问，消费触摸以避免不可见页面交互。
- 会话开始时固定显示模式；OFF 时立即处理网页 alert/confirm/prompt/beforeunload，避免独立提示框打断界面或挂起脚本。confirm/prompt 取消，alert/beforeunload 完成；ON 保留平台默认交互。
- ON 时保留 v0.19 官方网页对话框、等待时间和取消本条解析功能。
- 隐藏阶段 statusText 不存在，轮询增加空检查。仍在 loadUrl 后开始轮询，不依赖 onPageFinished；JS 代码、请求截止时间和匹配作品逻辑不改。
- 隐藏失败报告包含“网页显示=关闭”，错误详情提供“网页显示设置”按钮，打开原设置页。只有用户开启并重试才会显示；失败不会自动打开网页，也不会改写开关。
- 结束、失败、取消和 Activity 销毁后的原清理路径仍移除并销毁附着的 WebView。

本次属于可逆的界面/偏好调整，不新增镜像实现的单元测试；复用 152 项核心和 5 项网页脚本回归，完成 Android 编译、lint、APK 构建与签名检查。没有连接 Android 真机，需实测显示/隐藏、偏好持久化和隐藏读取兼容性；不声称手机端成功率已验证。
