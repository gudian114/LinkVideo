# v0.22 批量计数、多选和选择设置

## 批量页

- 顶部设置旁显示当前文本框数量 / 10，例如 1/10；新增、退格删除、一键清空和多选删除后同步更新。解析成功后计数入口仍保留，数量仍表示文本框数。
- 点击计数器进入选择，顶部恢复/切换为“删除”“全选/取消全选”“取消”。输入框选择时在链接编号旁勾选；视频选择时在已解析视频结果处勾选，视频编号与其链接号对应。
- 初始无勾选。全选只选当前类型；取消清空勾选并恢复原顶部。删除成功后退出选择。全部删除文本框时仍保留一个新的空框，其他情况下保留剩余卡片及其结果、下载位置并重新编号。
- 视频选择模式下，一键下载使用选中视频快照；例如选视频 1、3 只下载这两项。空选择提示先选择视频，不退回下载全部。取消选择后，一键下载恢复下载全部已解析视频。
- 选择期间禁止编辑、重新解析和一键清空，防止勾选对象变动；解析、下载及等待旧安卓存储授权时禁止删除/选择/增删输入框，避免队列索引错位。返回退出原页面仍会取消正在执行的队列。
- 旋转时通过既有 BatchState 序列化恢复选择类型和每项勾选状态；下载授权目标也保留。不新增自动后台下载。

## 单个设置：批量解析选择设置

三个互斥选项，默认第一个：

1. **优先选择视频**：有已解析视频就选视频，尚无视频就选文本框。删视频仅清除解析结果和其位置展示，保留链接。
2. **每次询问选择类型**：每次点击计数器先选“文本框”或“视频”；选文本框删除整张卡片，选视频只清除结果。没有已解析视频时提示先解析。
3. **视频与文本框同删除**：有视频时直接选视频，删除所选视频和其对应文本框；没有视频时选文本框。不会删除未选中的卡片。最后一个被删除后保留一个空框。

三个模式都不删除手机中已经下载的文件。

下拉框每行右侧都有问号；长按显示该选项专属帮助，轻点也可查看以便无障碍操作。帮助不会选择该项或修改偏好。“你粘贴的链接也会消失”仅出现在第三项帮助里，不显示在设置主界面或选项标题。

使用原生 PopupWindow 按设置按钮展开，列表可以滚动，每个问号与选项的点击事件分开。依据：[Android PopupWindow](https://developer.android.com/reference/android/widget/PopupWindow)、[长按事件接口](https://developer.android.com/reference/android/view/View.OnLongClickListener)。偏好只保存一个整数选项，未拆成两个设置。
