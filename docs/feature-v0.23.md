# v0.23 批量预览、返回保留与快捷滚动

## 批量结果预览

- 设置新增“批量解析后预览视频”，默认关闭。关闭时继续使用简洁结果；开启后，解析成功的卡片以主页同款视频结果替换链接输入区，失败项仍然可以编辑。
- 成功项标题为“视频 N”，编号与原链接编号对应。视频卡片包含自适应封面、播放/暂停、时间轴、播放时长、文案编辑与复制、作者/时长以及查看视频、复制视频链接、下载视频和下载封面。
- 播放另一条时先暂停并释放上一条播放器，保留上一条播放位置，再播放当前条。已经播完的视频再次播放从头开始。退出页面、切到后台、删除卡片或关闭预览时停止播放并释放资源。
- 中央按钮、底部按钮、时间轴与时间在播放时一起渐隐；单击调出，双击切换播放/暂停。复用主页布局、媒体选择和封面加载机制，不更改平台解析策略。
- 文案修改保存在各自卡片中，复制取得当前修改内容。选择模式沿用 v0.22，勾选哪些视频就下载哪些，空选择不会下载全部。
- 开启预览后，输入换行会跳过已展示视频的卡片，找到下一可编辑框或在末尾创建一框，仍最多十框。退格删空框后只会把焦点交给可见输入。

## 返回主页

- 设置新增“返回主页时是否清空批量解析内容”，默认关闭。默认保留已填链接、已解析结果、修改后的文案和已下载文件的位置，重新进入批量页恢复。
- 开启该设置后，返回主页清空批量草稿；重新进入只有一个空输入框。不会删除手机中已下载的文件。
- 打开设置或暂时进入后台不触发“返回主页清空”。后台仍有任务完成时更新保存结果。保存使用应用私有文件，先写临时文件再替换。
- 返回主页仍取消未完成队列；不新增后台下载服务。恢复的媒体地址可能过期，需要重新解析。重新打开页面不自动播放视频。

## 快捷滚动

- 批量页右下角提供应用配色的圆形向上、向下按钮，分别到顶部/底部；到达边界隐藏不需要的方向按钮。
- 列表底部保留空间，避免浮动按钮遮住末尾操作。

## 验证边界

新增草稿和状态回归测试覆盖保存恢复、替换与清空、文案隔离、混合卡片导航、十框上限和播放状态切换。没有 Android 真机或模拟器，实际播放器切换、手势、大字体和不同输入法仍需手机验证；构建、签名和源码归档检查记录见 verification.md。
