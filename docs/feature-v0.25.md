# v0.25 GitHub Releases 应用内更新

设置页新增“检查更新”，从固定地址读取 GitHub 最新 Release 的 `latest.json`。发现新版本后显示版本号、更新说明和安装包大小，下载过程显示进度并支持取消和失败重试。

安装前依次检查 HTTPS、文件大小、SHA-256、包名、版本号、版本名、最低系统版本和当前应用签名证书。任何一项不匹配都会禁止安装。下载文件保存在应用私有缓存，不申请公共存储权限，也不保存 GitHub Token。

Android 8.0 及以上缺少“安装未知应用”授权时进入本应用的系统授权页。通过校验后使用 `PackageInstaller.Session` 拉起 Android 系统安装确认界面，不进行静默安装。安装成功、用户取消和安装失败使用不同提示，未安装成功时当前版本保持不变。

本版本继续使用 v0.24 的包名和签名证书。自动测试和构建检查不等同于真机完成授权、取消和覆盖安装验证。
