# v0.28 抖音网页误弹修复

- 默认关闭“显示抖音解析网页”时，隐藏 WebView 不再因为启动满 4 秒而自动显示。
- 应用自己发起的详情请求返回 403、单次超时或脚本错误，只进入诊断，不再直接判定用户必须操作。
- 网页脚本仅报告屏幕内可见的滑块/拼图验证容器、验证 iframe 或精确验证提示；逐层检查父容器隐藏状态，不扫描或返回全页正文。
- 普通作品页或 iframe 只在查询参数里带 `verifyFp` 时不会被识别为验证页。
- 明确验证界面必须连续存在 5 秒才显示；短暂出现后自行消失的过渡验证保持隐藏。
- 没有滑块、只显示普通推荐内容的网页保持隐藏；隐藏等待超时后给出提示，可由用户在设置中主动打开网页重试。
- 用户在设置中主动开启“显示抖音解析网页”时仍立即显示，便于手动处理平台新增的验证形式。
- 保留 v0.27 的原生路线、Cookie 边界、90 秒总截止时间、OTA、下载、预览、图文及批量功能。

自动测试可以证明显示决策和网页脚本的输入输出，但不能证明抖音当前线上页面使用的 DOM 标记在所有设备上完全一致；实际滑块出现与自动消失时序仍需真机验证。
