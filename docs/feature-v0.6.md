# v0.6 原位视频预览

1. 结果卡顶部由单独封面改为固定高度的预览区，封面仍作为初始画面。
2. 点击封面或中央三角形后，使用 Android 原生 VideoView 在同一位置播放解析后的视频；不跳转浏览器。
3. 播放时中央图标切换为双竖线暂停键，并在 1 秒后渐隐；点击视频重新显示中央暂停键。
4. 底部控制条始终显示播放/暂停键和可拖动进度条。拖动结束后跳转到相应播放位置。
5. 暂停、播放结束和播放失败时显示三角形；播放结束后可从头播放。应用进入后台会暂停，重新解析、切换链接或退出会停止并释放旧播放器。
6. 视频请求继续携带解析器保存的 User-Agent、Referer 和必要 Cookie。
7. B站 DASH 结果额外尝试请求一条 HTML5 合并预览流。预览优先使用该流，下载仍使用原有 H.264 画面与 AAC 音频封装流程；合并预览不可用时回退画面轨，可能没有声音。
8. 四宫格按钮、下载进度、文件位置、封面备用加载和结果信息顺序不变。
