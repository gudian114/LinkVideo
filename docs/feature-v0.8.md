# v0.8 手动解析与输入四宫格

1. 删除输入内容变化后的自动解析；手动输入、粘贴文字或从其他应用分享文字都不会自行发起网络请求。
2. 输入区按钮改为两行两列：第一行“粘贴并解析”“解析”使用蓝色背景；第二行“重新解析”使用绿色背景，“清空链接”使用浅红色背景。
3. “粘贴并解析”读取剪贴板、填入输入框并立即解析；“解析”和“重新解析”解析当前输入框内容。
4. “清空链接”只清空输入框，不清除结果、不停止预览，也不影响已有的视频或封面下载功能。
5. 编辑输入、清空输入、新解析进行中以及新解析失败时都保留原结果；只有新视频解析成功后才停止旧预览并替换结果。
6. 三个平台的解析规则、下载、封面备用加载及 v0.7 播放器交互保持不变。
