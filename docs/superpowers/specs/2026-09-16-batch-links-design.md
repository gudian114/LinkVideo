# v0.14 批量链接设计

## 已授权范围

- 主页增加固定顶部开发水印“由@UMG_gudian114开发”，右侧使用传统齿轮设置图标。
- 主页在平台名称下方、分享输入卡片上方增加“批量解析”入口，进入独立页面。
- 初始只有一个输入框，新增下一项时复用已有下一项；最多 10 项。
- 回车/键盘换行/退格新增或切换到下一项，保留当前框全部内容；退格不执行删除。普通多行分享文案粘贴保持在同一项。
- 批量功能仅限视频。检测到图文时弹窗“此操作仅限与视频批量解析”，该项不保存图文结果，继续其他链接；主页单条图文功能保持原样。
- 每项默认三个按钮：蓝色“解析”占满上行，绿色“重新解析”和浅红色“清空链接”平分下行。
- 设置新增三个 ON/OFF 开关，标签逐字使用用户提供文字，初始全部 ON。启用一个按钮时占满；两个按钮上下各占满；三个按钮恢复上述布局；全部 OFF 时仅保留输入与底部操作。
- 底部依次为蓝色“一键解析”、绿色“一键下载”、浅红色“一键清空”，均占满宽度。

## 数据与任务

BatchState 管理最多 10 项的输入和成功解析结果。修改或清空输入只清空链接，不删除已解析结果或已下载文件；新的成功结果替换对应项，失败保留原结果并显示错误。

复用 VideoParser 的阶段进度和 VideoDownloader 的 MP4 保存流程。批量操作按项顺序执行，单项异常或图文记录在该项并继续。下载只选视频结果；批量页不跳转图文页，同时只显示一个图文限制弹窗以避免堆叠。

任务期间禁用输入和重复操作，防止队列读取到正在变化的链接。退出页面终止队列并取消当前任务；已有下载器负责清理未完成输出。旋转重建保存输入与解析结果，正在执行的任务终止后可重新开始。

## 验证与交付

为上限、下一项复用、空项跳过、清空输入保留结果、视频下载筛选和状态序列化写核心行为测试。执行现有回归、资源编译、Android Java 编译、Lint、APK 构建与签名验证。没有设备时明确区分核心检查和真机 UI 验证。
